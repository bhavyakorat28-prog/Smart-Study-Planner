\# Smart Study Planner 📚



A web-based Smart Study Planner developed as a university hackathon project.



\## About



Smart Study Planner is designed to help students organise their study activities and manage their study sessions through a simple web interface.



\## Technologies Used



\- HTML5

\- CSS3

\- JavaScript



\## Project Structure



\- `index.html` — Main application page

\- `css/style.css` — Application styling

\- `js/app.js` — Main application functionality

\- `js/timer.js` — Study timer functionality



\## Project Type



Frontend Static Website



\## Purpose



Developed as part of a university hackathon project to explore practical web development and student productivity solutions.
